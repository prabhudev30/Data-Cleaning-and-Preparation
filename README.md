# Data Cleaning and Preparation Project

## Overview

This project demonstrates data cleaning and preparation using Python Pandas.

The goal is to improve dataset quality by identifying missing values, removing duplicate records, checking data types, and exporting a cleaned dataset.

## Tools and Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy

## Dataset

Dataset used:
Global Superstore Sales Dataset

The dataset contains sales information including:

- Order ID
- Category
- Sales
- Profit

## Data Cleaning Steps Performed

### 1. Data Loading

Loaded the CSV dataset into a Pandas DataFrame.

### 2. Dataset Exploration

Analyzed:
- Dataset structure
- Column information
- Data types

### 3. Missing Value Handling

Checked all columns for missing values.

### 4. Duplicate Removal

Identified and removed duplicate records.

### 5. Data Type Verification

Checked and verified column data types.

### 6. Export Cleaned Dataset

Saved the processed dataset as:

`Cleaned_Final_Global_Superstore.csv`
